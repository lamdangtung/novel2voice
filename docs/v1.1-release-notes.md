# v1.1 — Release notes dự kiến

29/10/2026 · chưa phát hành, phiên bản thực thi1.0.0. T01–T33 đã nghiệm thu kỹ thuật; T34 chờ đánh giá giọng và dịch API thật.

Web app Vue/Vite/Tailwind tách FastAPI/SQLModel, có launcher app/API/worker. Thư viện theo truyện, import TXT/MP3 có preview và ánh xạ, phiên bản nguồn/glossary, cấu hình kế thừa và catalog/mẫu giọng riêng.

TTS, dịch, process và ghép chạy nền với snapshot, checkpoint, dừng/tiếp tục/phục hồi/retry. Audio có xác minh hash/thời lượng, player/Range/download; dashboard phân biệt audio hiện hành và job cần xử lý. Không ghi đè output tốt trước khi file mới hợp lệ. Ghép MP3 có fallback reencode khi padding concat làm lệch thời lượng.

Bảo vệ local Host/Origin/upload/path/secret; chống hai job cùng chương và hai writer CLI/web cùng output/cache. Backup toàn thư viện có maintenance gate, SQLite backup và manifest/checksum; restore vào kho mới.

Schema web version3 có backup trước nâng cấp từ version1/2, hỗ trợ22ngôn ngữ nguồn và prompt dịch tương ứng. Không tự thay DB/audio CLI cũ. Hành vi CLI/checkpoint được kiểm tra tương thích. API và frontend có lockfile; requirements.lock bổ sung cho CLI/VieNeu.

Nghiệm thu:96API,20CLI, regression padding/output lock và build PASS. Flow tích hợp giả lập PASS; VieNeu thật hai truyện, cài mới và cache0call PASS. Giọng thật cần đánh giá chủ quan; dịch API thật chưa chạy, các provider khác chưa được xác nhận hoàn toàn. Không dùng kết quả này để tuyên bố v1.1 đã phát hành.
