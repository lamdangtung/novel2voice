# T07 — Nhập thư mục server

Đã triển khai và kiểm tra tự động. Mở một truyện → Hoặc chọn thư mục trên server. Chỉ có input/ và (khi --verification) fixture của workspace T02 đã sở hữu. Không phải đường dẫn file trên máy browser.

Chạy `uv run --project api --frozen python -m api.verification init --workspace demo` rồi launcher --verification. Chọn fixture:demo → books → A → tắt đệ quy → xem trước thấy 1/2; hủy hoặc xác nhận → bật Bao gồm thư mục con → xem trước có ep2/10 và en/1 → lựa chọn chương cần nhập → xác nhận. Bản EN và VI cùng số cần bỏ chọn hoặc đổi số một file; không tự gộp chúng.

Giới hạn 2000 entries/20 TXT/256KiB mỗi TXT/2MiB tổng. Kiểm tra toàn bộ candidate path/link trước khi đọc nội dung; đường dẫn ngoài vùng, symlink/hardlink bị từ chối. Chọn thư mục có trạng thái đang tải để tránh dùng nhầm đường dẫn trước đó. Sửa file nguồn sau preview thì confirm yêu cầu xem trước lại. Nguồn không bị sửa.

Test API recursion, path/link trước đọc và freshness đạt; browser trong [báo cáo](T07/browser-report.json), [ảnh preview](T07/folder-preview.png). Test nằm trong test_folder_updates.py (5 test dùng chung T07/T08). Không có endpoint đọc đường dẫn tùy ý. Chạy lại trên truyện mới hoặc bỏ qua nội dung giống hệt bằng flow T08.
