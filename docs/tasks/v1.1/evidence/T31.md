# T31 — VieNeu thật

29/10/2026 · nghiệm thu kỹ thuật agent_verified; chất lượng giọng chờ người dùng nghe.

Môi trường hiện tại: VieNeu3.8.3, v3turbo CPU; dùng model ONNX trong cache HuggingFace sẵn có. HF_HUB_OFFLINE=1 và TRANSFORMERS_OFFLINE=1 trong phiên thử; không tải model hoặc gọi dịch vụ trả phí. Giọng và SHA/output/job ID đầy đủ trong T31/real-provider-report.json.

Thử mẫu thật3,68giây:1lần gọi,2,91giây thực thi. TTS một chương ngắn:1lần gọi,2,24giây. Chạy lại:0lần gọi, tái sử dụng đúng artifact/hash. ffprobe/hash qua kiểm tra. Không coi thời gian này là benchmark cho chương dài.

Cài backend web bằng uv sync --project api --frozen; SDK TTS ở root `.venv`: `uv venv .venv` rồi `uv pip install --python .venv/bin/python -r requirements.txt`. VieNeu đã pin3.8.3 trong requirements. Cài FFmpeg/ffprobe trên máy và kiểm tra trang Môi trường trước khi chạy. Lần đầu thiếu model có thể phải tải theo SDK; phiên nghiệm thu này dùng cache sẵn.

Provider khác: Edge/OpenAI chưa nghiệm thu dịch vụ thật; OpenAI cần key/chi phí do người dùng chọn riêng. Piper có file model trên máy nhưng module chưa cài, doctor báo rõ; không tuyên bố đã hỗ trợ runtime hiện tại. Không cài tất cả provider khi chỉ dùng VieNeu.

Chạy lại qua web: chọn provider VieNeu/giọng trong truyện → thử câu ngắn → xem kế hoạch → xác nhận → nghe mẫu; import một TXT VI ngắn → TTS → chạy lại kiểm tra0call. Kho nghiệm thu riêng `.verification/workspaces/t31-real/web`, không dùng dữ liệu production. File sample lưu trong job-results/9764bbb3-ddb8-53e2-afc0-5324c4770509/sample.mp3.
