# T26 — Trạng thái key và kết nối server

Đã triển khai và nghiệm thu tự động, làm trước T22 theo phụ thuộc. Mở #settings hoặc cấu hình riêng truyện → Kết nối và key tại server: thấy provider/model/endpoint đã giải quyết và có/chưa có OPENAI_API_KEY/HF_TOKEN. Trạng thái chỉ chứng minh đã cấu hình, không xác minh hiệu lực/quota và không gọi dịch vụ.

Không có form nhập key. Cấu hình ở .env gốc/biến môi trường launcher; biến môi trường ưu tiên, restart khi đổi biến của tiến trình. API chỉ trả bool; endpoint bỏ user/password/query/fragment và thay chuỗi key nếu xuất hiện trong phần còn lại. Form cấu hình thường không nhận trường key, không ghi chuỗi dấu che hoặc rỗng lên key. Thiếu key OpenAI chặn trước request dịch vụ; translator giả lập không cần key.

3 test redaction/presence/không ghi key và browser hai process QA (key rỗng rồi key giả) đạt. Lưu cleanup thông thường vẫn giữ key server. Không có key thật được nhập/gọi hoặc file .env người dùng bị sửa. [Chưa có key](T26/missing-key.png), [đã cấu hình và redacted](T26/configured-redacted.png), [báo cáo](T26/browser-report.json).
