# T14 — Phát, tua và tải MP3

Đã triển khai và kiểm tra tự động. Mở chương có audio → player native → phát → tua giữa/cuối → chọn chương khác: audio cũ dừng và được tháo ngay trước khi tải detail mới → chọn audio nếu có nhiều bản → tải MP3 và đối chiếu SHA256. Audio nhập trước/cần kiểm tra lại có cảnh báo.

GET books/{book}/audio/{artifact} hỗ trợ HTTP Range (FileResponse), query download=true tải attachment. Kiểm tra book ownership, path/link, size và checksum bằng đọc từng block, không nạp toàn MP3 vào RAM API. File mất trả404; checksum đổi trả409; player hiện lỗi và nút kiểm tra lại. Artifact ID khác truyện không truy cập được. Range ngoài file trả416.

Browser thật dùng tone2giây: phát, seek1.4giây, byte-range100–199 trả206 đúng bytes, download nguyên byte, đổi chương chọn ID khác, cập nhật TXT có cảnh báo. Test tự động kiểm tra file mất/tamper và wrong-book. [Player](T14/player.png), [mobile](T14/mobile.png), [báo cáo](T14/browser-report.json). Đây là nghiệm thu âm thử, chưa phải chất lượng giọng thật.
