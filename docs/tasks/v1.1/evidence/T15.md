# T15 — Queue và worker nền

Đã triển khai và kiểm tra tự động. Launcher khởi động worker riêng với app/API. Chạy --verification, mở #jobs, chọn truyện kiểm thử → tạo hai job thử liên tiếp → thấy job đầu running, job sau queued → chuyển trang/reload → API stop/start → xem cả hai completed với6 bước/job, mỗi bước chỉ bắt đầu một lần. Provider giả lập; không gọi AI/TTS thật. Nút dừng/recover chưa xuất hiện ở T15.

Job lưu SQLite; BEGIN IMMEDIATE claim nguyên tử và filelock đảm bảo một worker trên thư viện. API và worker dùng session riêng; worker không bị api stop dừng. Heartbeat worker phản ánh health. GET jobs/jobs/{id} polling lấy trạng thái/progress/events/report; POST jobs/verification chỉ có khi --verification. RequestUUID chống submit trùng. Mỗi job có vùng kết quả/log riêng, không ghi lên audio chương. Bình thường chưa có action nghiệp vụ để tạo job ở task này.

Hai test enqueue/claim/retry/progress/failed fake đạt. Browser tạo hai job, API phản hồi trong lúc worker bận, tiếp tục khi API dừng, reload và6calls/job đạt. [Queue](T15/queued-running.png), [hoàn thành](T15/completed.png), [báo cáo](T15/browser-report.json). Nếu kill worker giữa job, trạng thái running có thể còn; phục hồi/dừng an toàn thuộc T19/T20, không hứa resume ở đây. quit/Ctrl+C launcher dừng các process do nó tạo; không dừng launcher khác.
