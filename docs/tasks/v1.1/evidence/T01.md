**Trạng thái:** đã được người dùng chấp nhận sau đổi stack và yêu cầu tiếp tục T02; Linear đã chuyển Done. Phiên bản phần mềm vẫn v1.0.0; chưa phát hành v1.1.

- `app/`: **Vue 3 + Vite + Tailwind CSS**, Composition API và `<script setup>`; sidebar theo mock, component kết nối API, composable quản lý trạng thái, API client riêng.

- **uv** quản lý Python qua `api/pyproject.toml` và `api/uv.lock`, môi trường riêng `api/.venv`.
- **pnpm** quản lý frontend qua package.json và pnpm-lock.yaml; dependency trực tiếp pin exact.
- **SQLModel + SQLite** đã pin/cài và smoke test trong bộ nhớ. Chưa tạo bảng hoặc migrate dữ liệu nghiệp vụ; phần đó thuộc T04.
- Launcher một lệnh quản lý Vite và API; app vẫn được phục vụ khi API dừng. Không cần database/worker/model/API key để mở T01.
- [ADR 002](../../../decisions/002-vue-fastapi-sqlmodel.md) thay thế quyết định buildless ban đầu. Bản mock đã duyệt giữ nguyên.

## Cài đặt và chạy lại

Từ root repository `/Users/lamdt/Desktop/novel2voice`:

```bash
pnpm --dir app install --frozen-lockfile
uv sync --project api --frozen
uv run --project api --frozen python -m api.dev
```

Nếu launcher T01 cũ đang chạy, dùng `quit`/Ctrl+C ở terminal cũ trước khi chạy lệnh mới. Không mở hai launcher trên cùng cổng. Không mở index.html trực tiếp; dùng Vite do launcher khởi động.

## Flow verify chính

1. Chạy launcher ở trên. Mở **http://127.0.0.1:8000**.
2. Thấy Tổng quan, sidebar, trạng thái **Đã kết nối**, phiên bản API **1.0.0**; không có thống kê truyện giả.
3. Bấm Thư viện truyện, Công việc, Cấu hình, Môi trường rồi Tổng quan. Mỗi màn hình ghi đúng phạm vi chưa triển khai.
4. Nhập `api stop` trong **terminal launcher**, chờ thông báo đã dừng.
5. Trở lại browser, bấm Kiểm tra lại nếu chưa tự kiểm tra khi focus. Thấy **Mất kết nối**, nút **Thử lại**.
6. Reload khi API vẫn dừng: sidebar và giao diện Vue/Vite vẫn tải được, health báo lỗi.
7. Nhập `api start` ở terminal launcher, chờ API sẵn sàng; bấm Thử lại. Thấy **Đã kết nối** trở lại.
8. Lặp bước 4–7; không có process API trùng. Chỉ launcher đọc lệnh terminal; Vite không nhận nhầm stdin.
9. Mở **http://127.0.0.1:8001/docs** → mở `GET /api/v1/health` → **Try it out → Execute**. Thấy HTTP **200**, response đúng schema. JS/CSS Swagger được phục vụ local.
10. Nhập `quit`/Ctrl+C. Vite/Uvicorn cùng dừng và giải phóng cổng; chạy lại launcher được.

Dùng cổng khác khi cổng mặc định đang bận:

```bash
uv run --project api --frozen python -m api.dev --app-port 8100 --api-port 8101
```

Khi đó app ở 8100, Swagger ở 8101. Frontend tự nhận cổng API. Các ảnh kiểm tra bên dưới dùng cặp cổng này.

## Kiểm tra và bằng chứng

Frontend:

```bash
pnpm --dir app build
```

Kết quả: Vite build thành công. `pnpm --dir app install --frozen-lockfile --offline` cũng đã chạy thành công với cache sau lần cài đầu; lockfile không lệch.

API với môi trường uv mới:

```bash
uv run --project api --frozen python -m unittest discover -s tests -p 'test_web_shell.py' -v
```

**11/11 test thành công**: health không cần DB/worker, Host/Origin, mutation/CORS, lỗi/cổng cấu hình, OpenAPI typed response, Swagger local và SQLModel CRUD trên SQLite trong bộ nhớ.

Lõi CLI/TTS trong môi trường cũ:

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_tts_jobs.py' -v
```

**20/20 test thành công**. Tổng cộng **31 test qua hai môi trường**. Không dùng môi trường API để chạy test TTS khi chưa cài dependencies TTS, và không yêu cầu thêm model chỉ để test API.

Đã kiểm tra browser thật:

- Điều hướng cả 5 mục sidebar; không lỗi JavaScript.
- Dừng/bật **API thật**, reload frontend lúc API dừng và retry kết nối lại.
- Màn hình hẹp 390px không tràn ngang toàn trang.
- Host lạ bị từ chối (Vite hoặc boundary trả 400/403); `.env`, `src/config.py`, manifest repository không được phục vụ.
- Swagger Try it out trả HTTP 200; không có request ngoài origin API khi mở/thử docs.
- Process group của launcher kiểm thử được dừng sau khi kiểm tra.

Không commit trong task này; [source-checksums.json](T01/source-checksums.json) ghi hash nguồn/lockfile đã bàn giao để đối chiếu working tree.
