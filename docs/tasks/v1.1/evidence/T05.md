# T05 — Tạo, xem và sửa truyện

Đã triển khai và kiểm tra tự động. Chạy launcher từ root project:

```bash
uv run --project api --frozen python -m api.dev --verification
```

Mở http://127.0.0.1:8000/#library. Tạo A (VI), B (EN) → mở A → sửa tên/ngôn ngữ → refresh → quay thư viện → mở B → `api stop` / `api start` trong launcher → mở lại A/B. ID và thông tin giữ nguyên. Tên rỗng không lưu; request UUID chống tạo trùng khi retry/đồng thời; revision tránh ghi đè từ tab cũ.

API GET/POST /api/v1/books, GET/PATCH /api/v1/books/{id}; schema trong Swagger. Vùng lưu dùng UUID, không dùng tên truyện làm đường dẫn. Chế độ thường: `.novel2voice/library.sqlite3` và `books/<uuid>/`; kiểm thử: `.verification/web/`. Hai vùng bị Git ignore, không dùng input/output của CLI. Không có xóa vật lý.
