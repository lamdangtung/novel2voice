# T10 — Xem và tải TXT

Đã triển khai và kiểm tra tự động. Mở truyện → bấm tên chương → xem văn bản gốc, revision, byte/SHA256 → Tải TXT văn bản gốc → đối chiếu nguyên byte với file đã nhập. Chưa có bản dịch thì thông báo rõ; bản dịch cần verified=true mới hiện. Mở chương khác hoặc ID không tồn tại cho kết quả phù hợp.

GET chapters/{chapter_id}, GET artifacts/{artifact_id}/download trong scope truyện. Kiểm tra sở hữu, relative path, symlink/hardlink, giới hạn file và checksum trước đọc/tải. ID từ truyện khác trả404. Không nhận đường dẫn file trực tiếp. Source hiện tại lấy theo source_hash; các bản cũ vẫn giữ riêng.

Test UTF8/xuống dòng, download byte-identical, wrong IDs/book isolation và tamper checksum đạt; browser tải TXT cập nhật có CRLF/tiếng Việt/emoji đối chiếu nguyên byte.
