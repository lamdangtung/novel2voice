# T06 — Upload TXT, xem trước và xác nhận

Đã triển khai và kiểm tra tự động. Dùng launcher --verification, mở #library → tạo/mở truyện → Nhập chương từ TXT.

Chọn 1/2/10_vi.txt và file rỗng/UTF8 lỗi trong fixture T02 → Xem trước → thấy file lỗi không chọn được, số chương có thể sửa → xác nhận ba file hợp lệ → thấy 1/2/10 đúng thứ tự → refresh/restart vẫn còn. Phiên preview chưa tạo chương; Hủy phiên nhập không tạo chương. Confirm lặp cùng lựa chọn không nhập trùng. File gốc còn nguyên; bản quản lý giữ byte/BOM/xuống dòng, SHA256 và provenance.

Giới hạn server/client: 20 TXT, 256 KiB mỗi file, tổng 2 MiB; body HTTP tối đa8MiB. Truyền JSON base64 để dùng cùng boundary JSON/Origin/header; tên upload không nhận path. Chỉ UTF8/UTF8BOM, không NUL. Confirm trong transaction và dọn file đã tạo nếu thất bại; nguồn staging bị đổi thì từ chối. Phiên có ID và GET lại qua API; UI chưa khôi phục preview sau reload, hãy xem trước lại. Preview chưa xác nhận có thể giữ staging trên đĩa; chưa có tự động dọn theo thời gian.
