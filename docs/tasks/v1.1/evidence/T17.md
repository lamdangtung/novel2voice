# T17 — TTS một chương VI

Đã triển khai và nghiệm thu tự động. Chạy launcher --verification, mở truyện VI đã nhập TXT → chọn một chương → action TTS → Xem kế hoạch → xác nhận → xem tiến độ đoạn thực ở Công việc → về truyện, mở chương để nghe/tải.

Worker API dùng bridge subprocess Python `.venv` CLI, gọi TTSJobRunner/TextChunker/AudioMerger hiện có; không cài SDK/model vào api/.venv. Provider sản xuất có adapter, QA mặc định luôn fake, audio là tone. Cấu hình server/model được fingerprint và kiểm tra trước chạy; file model không được nạp khi chỉ preview. File cuối chỉ attach vào chương sau ffprobe/hash và kiểm tra source revision lần nữa.

Chạy lại cùng nội dung/giọng/cấu hình: kế hoạch tái sử dụng artifact, 0 call provider. Đổi voice hoặc TXT: fingerprint/source khác nên tạo bản mới, bản trước vẫn giữ. Checkpoint/chunk cache tách theo truyện, có hash kiểm tra. Không ghi đè audio đang chọn bằng partial. Tiến độ đọc số đoạn thật từ checkpoint SQLite, không dùng timer giả.

Unit qua bridge thật và browser đều đạt. [Tạo mới](T17/generated.png), [tái sử dụng](T17/reused.png), [báo cáo](T17/browser-report.json). Browser ghi số call mới >0, lần hai=0/cùng artifact, đổi voice có artifact mới, play/download đạt. Giọng thật thuộc T31; không dùng tone để tuyên bố chất lượng TTS.
