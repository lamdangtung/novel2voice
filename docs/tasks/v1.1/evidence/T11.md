# T11 — Cấu hình workspace và từng truyện

Đã triển khai và kiểm tra tự động theo ủy quyền tiếp tục backlog. Chạy launcher --verification, mở #settings, đặt provider/voice/chunk/concurrency/retry/cleanup/model dịch và lưu. Mở truyện A → Cấu hình riêng cho truyện → tick Đặt riêng ở voice → lưu. B không đặt riêng sẽ kế thừa. Đổi mặc định workspace → A giữ voice riêng, các trường còn lại nhận mặc định mới, B kế thừa toàn bộ. Reload/restart vẫn giữ kết quả. Bỏ tick rồi lưu để trở lại kế thừa.

API capabilities xác định khả năng chọn voice theo provider; Piper không có voice selector (dùng model tại server). Giá trị hiệu lực và nguồn server/workspace/book hiện ở form. Giới hạn: chunk100–10000, concurrency1–16, retry0–5; API và UI đều validation. Không nhận key/token trong form hoặc payload. Lưu có revision chống ghi đè tab cũ; file JSON atomic trong vùng quản lý, có lock và từ chối link. `.env` không bị sửa. Mặc định có thứ tự book override > workspace > server.

Endpoint GET/PUT /api/v1/books/workspace/settings và /api/v1/books/{id}/settings; GET workspace/capabilities. Cấu hình mới chưa tự thay lệnh CLI cũ; T16 sẽ snapshot cấu hình cho job. Hai test kế thừa/persistence/validation/concurrency conflict đạt; browser defaults → own A → change defaults → B inherits → restart → Piper hides voice → retry âm bị chặn → mobile đạt.
