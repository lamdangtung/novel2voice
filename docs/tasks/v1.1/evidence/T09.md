# T09 — Tìm/lọc và chọn chương

Đã triển khai và kiểm tra tự động. Mở truyện có >20 chương → trang đầu hiển thị 20 theo số tự nhiên → chọn vài chương → Sau → chọn thêm → xem ID đã chọn. Lựa chọn giữ khi đổi trang/bộ lọc, không lẫn truyện. Chọn tất cả chỉ thêm các chương trên trang đang hiện. Bỏ chọn tất cả rồi thêm khoảng1–10: phạm vi là toàn bộ truyện hiện tại, không áp dụng bộ lọc; UI ghi rõ.

Tìm số/tên, lọc có văn bản/audio đã xác minh/audio cần kiểm tra lại → Áp dụng; rỗng có thông báo. API phân trang GET chapters (offset/limit<=100, UI20), GET chapter-selection start/end (tối đa5000). Chưa có action tạo job; ID lựa chọn xem được. Selection chưa lưu qua reload.
